dsh-session-export↗ v0.2.0

DSH 的会话日志是一串拼接的 zstd 帧，事件流里混着 user/message、 tool/call、tool/result 和自己的元数据。原生只能靠网页上 一个「复制为 Markdown」的按钮——那是给手用的，模型够不到。 这个插件把整条链路做成工具：解析帧、剥掉宿主注入的 system-reminder 与运行时上下文、 输出 Markdown / HTML / JSON；index 模式把所有会话压进一个自包含 HTML， 纯前端搜索，断网可用。

local-draw 在做

dsh-go 原生插件：manifest 里声明胶囊和面板，App 只负责渲染我推的视图 JSON，图片字节落在插件自己的 assets/ 目录，用 asset: 引用。生成不在端上跑——实测这颗芯片出 512px 要两分钟、结果还糊，瓶颈是模型不是参数。所以改成多后端自动择优， 无密钥时落到免账号的 FLUX 通道。免费额度有个坑：45 秒一张，而且会偷偷缩图—— 请求 2048×1536，回来的是 886×665，这个数字现在就写在插件的错误提示里。
